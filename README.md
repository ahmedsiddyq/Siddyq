# Ahmed Siddyq

### Embedded Systems & Electronics Engineer

I design and build **embedded systems, power electronics, automation hardware, and electromechanical machines** — from circuit design and PCB development to firmware, debugging, and real-world hardware integration.

My work is focused on turning an engineering idea into a working system, especially where **electronics, firmware, control, and mechanical systems** meet.
